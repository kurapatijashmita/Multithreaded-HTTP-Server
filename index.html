C++ Multithreaded HTTP/1.1 Server

Welcome! This is an educational HTTP/1.1 Server built with C++17 and Windows Sockets (Winsock2).

Quick Links:
• GET /health - Check server health (JSON)
• GET /status - View server uptime and request metrics (JSON)

Supported Routes & Status Codes

Method Path Status Description
GET / 200 OK Serves this homepage (HTML)
GET /health 200 OK Returns health status (JSON)
GET /status 200 OK Returns server metrics (JSON)
GET /other 404 Not Found Unknown route
POST Any 405 Method Not Allowed Only GET is supported
Invalid Any 400 Bad Request Malformed HTTP request line
